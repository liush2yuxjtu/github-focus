编辑解读

解释意义，不替代验收

主线、意义与下一步来自对公开变更的分析。commit 标题记录作者的描述；出现「QA」「verify」不等于本页面独立重跑过验证。合并也不代表已经部署。

边界

公开、有限、按需

没有读取或发布私有仓库内容、聊天全文、令牌或用户数据。不是全部项目排名，不计算生产力，也没有定时监控。刷新浏览器仍读取本次快照。

分支提醒

别把 main 当成全部

A Dark Room PR #34 的目标是 cursor/godot-chinese-remake-5c3a，所以默认分支 commit 与近期 PR 的时间可能不同。线上生效仍需在部署环境验证。

想知道主线是否又有新变化？

按需比较三个主线仓库的默认分支 HEAD。只检查新提交，不会自动改写解读，也不覆盖非默认分支或 PR 的新变化。
